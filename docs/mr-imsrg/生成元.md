# 生成元：White-NCSM

代码：`Generator::ConstructGenerator_WhiteNCSM`（`src/Generator.cc`），参数 `core_generator=white-ncsm`，要求 `denominator_partitioning=Epstein_Nesbet`。
定义取自 Vobig 2020 第 6.5 节（6.5.13–6.5.14 掩码，6.5.28–6.5.34 分子与分母），与 IM-NCSM 文献的生产选择一致。

## 1. 为什么只有这一个

imsrg++ 原有的生成元（white、atan、imaginary-time 等）都按 SR 的空/满占据和 core/价空间划分构造。MR 要解耦的是 Nmax_ref 盒子与外部，
占据是分数的，需要（1）按 Δe 选块的掩码，（2）占据加权的分子，（3）含占据的 MR-EN 分母。所以 MR 模式只接受 `white-ncsm`，其他生成元在启动时拒绝。

## 2. 定义

掩码：只对 Δe ≠ 0 的元素生成 η，e = 2n + l 取自然轨道继承的 HO 槽位标号（见 参考态输入.md 的标号规则）。

- 一体：同 (l, j, tz) 的 i ≠ j，且 e_i ≠ e_j；
- 两体：同通道的 bra、ket，且 e_p + e_q ≠ e_r + e_s。

分子（不含 λ2）：

- η_ij = f_ij [ n̄_i n_j / Δ_ij − n̄_j n_i / Δ_ji ]，n̄ = 1 − n；
- η_{(pq),(rs)} = Γ_{(pq),(rs)} [ n̄_p n̄_q n_r n_s / Δ_{pq,rs} − n̄_r n̄_s n_p n_q / Δ_{rs,pq} ]。

分母（MR Epstein–Nesbet，Vobig 6.5.31、6.5.33–6.5.34），W 为对应方向的占据乘积：

- 一体：Δ_ij = −n̄_i² n_j² Γ̄_ijij + n̄_i² n_j f_ii − n̄_i n_j² f_jj + E (n̄_i n_j − 1)；
- 两体：Δ_{pq,rs} = W [n̄_p n̄_q Γ̄_pq + n_r n_s Γ̄_rs − n̄_p n_s Γ̄_ps − n̄_p n_r Γ̄_pr − n̄_q n_r Γ̄_qr − n̄_q n_s Γ̄_qs
  + n̄_p f_pp + n̄_q f_qq − n_r f_rr − n_s f_ss] + E (W − 1)，W = n̄_p n̄_q n_r n_s；

Γ̄_ab 是单极矩阵元 `GetTBMEmonopole(a,b,a,b)`；|Δ| < 1e-6 时取 1e-6。SR 极限（n = 0/1）下 W = 1，回到普通 White-EN。

分子丢掉 λ2 是文献的选择（Vobig 6.5.28–6.5.29）；对易子里的 λ2 保留。`.mrmeta.json` 的 `generator_numerator_lambda` 字段记录这一点。

## 3. 实现

- 单极矩阵元按轨道对预先缓存（OpenMP 按轨道并行）；
- 两体部分按二体通道并行（每个通道只写自己的 η 块，与 imsrg++ 其他生成元相同）；输出与线程数逐位无关；
- 一体部分 1B 只连接同 (l, j, tz)，掩码在 1B 上实际不排除任何非对角元，保留全轨道循环是为了让 Δe 定义写在代码里。

验证：`MRDenominators` 把每个选中的分母与 m-scheme oracle 比较；`MRCorrelatedDriver` 检查真实相关参考态的 η 与短流。

## 4. 已知问题：慢尾

现象：‖η‖ 先快后慢。He4 Nrefmax=2 emax2 到 ‖η‖/‖η0‖ < 1e-6 需要约 8×10^5 个 Magnus 步（s ≈ 4×10^5，单线程 44 h）；
s = 100→1000 的包络衰减率只有约 2.3e-3。

来源（已确认）：分母 Δ = W·ε + (W − 1)E。W ≪ 1（小占据轨道参与的方向）时，该通道的衰减率 κ ≈ Wε / (Wε + (1 − W)|E|)，
White 生成元的单位衰减率丢失；参考态里有 2e-4、2.5e-3 量级的自然占据，这些通道在快通道消失后主导 ‖η‖。
不是 ODE 容差或小分母造成的：s = 1000 主导通道的分母约 24 MeV。

诊断工具（直接调用生产生成元，把 η 拆成逐通道的分子、正反分母与贡献）：

```bash
python3 prototype/mrimsrg/diagnose_white_ncsm_tail.py --reference X.jref --nucleus He4 --emax 2 \
    --hamiltonian s0=H0.jcoupled64 --hamiltonian s1000=H1000.jcoupled64 [--top 20] [--output tail.json] --pyimsrg-dir build/src
```

可能的修改（改变已发表的生成元，需要决定后再做，见 TODO）：分母里的占据因子（按 W 归一、处理 (W − 1)E 项），或改用 Brillouin 型分子。
在此之前，长流靠 `magnus_adaptive` + 大 `smax` + `eta_criterion` 跑完；有限 s 截断的做法见 `select_downstream_flow_window.py`
（按下游 Nmax 序列判断有限 s 点是否可用，Vobig 6.5.5 节，只作加速，不是收敛的 MR-IMSRG 结果）。
