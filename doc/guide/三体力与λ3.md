# 三体力（MR-NO2B）与 λ3

代码：`src/MRThreeBody.{hh,cc}`（MR-NO2B）、`src/MRCommutator.cc`（`comm220_lambda3`）、`prototype/mrimsrg/lambda3.py`（λ3 生成）。
生成元不变（White-NCSM，分子不含 λ）。

## 1. 做的是什么

三体力只在流开始前进入一次：相对相关参考态做 MR 正规序，保留零、一、两体，丢掉剩余的正规序三体（MR-NO2B，Hergert 2017 式 41–43）：

| 部分 | 公式 | 用到的密度 |
|---|---|---|
| E3 | (1/36) Σ V3·γ3，γ3 = A(γ1γ1γ1) + A(γ1λ2) + λ3 | γ1、λ2、λ3 |
| f3 | ¼ Σ V3·γ2，γ2 = A(γ1γ1) + λ2 | γ1、λ2 |
| Γ3 | Σ V3·γ1 | γ1 |

之后的流、Magnus、算符演化与纯 NN 完全相同。导出的 H 自带 3N 的 MR-NO2B 贡献，下游 NCSM/FCIQMC 直接用。

λ3 出现在两处：

1. 上表 E3 的 λ3 项（需要 3N 的一般矩阵元）；
2. 对易子零体项 ¼ Σ (X^{ab}_{cd} Y^{kl}_{am} − Y^{ab}_{cd} X^{kl}_{am}) λ^{bkl}_{cdm}（Hergert 式 49 最后一项），只用两体的 X、Y，与 3N 无关，纯 NN 也有。
   流的每一步（Magnus 导数、BCH）和标量算符的变换都经过它；张量没有零体，不受影响。

两处都只改变零体：导出 H 的常数项（绝对能量）和标量算符的期望值常数；激发谱、跃迁不受直接影响，
只通过 White-NCSM 分母里的 (W−1)E 间接影响流的路径。文献（Vobig、Mongelli）全程取 λ3 = 0。

## 2. 规则：有就用，没有就不用

不加输入参数，按输入自动判定，日志与 `.mrmeta.json` 写明：

| 3N 输入（`3bme_type`） | γ1、λ2 部分 | λ3·V3 零体项 | 对易子 λ3 项 |
|---|---|---|---|
| 无（`3bme=none`） | — | — | jref 有 λ3 就加 |
| `no2b` | 算 | **不算**（no2b 文件缺这项需要的矩阵元），日志注明 | jref 有 λ3 就加 |
| `full` | 算 | jref 有 λ3 就加，打印数值 | jref 有 λ3 就加 |
| `mono` | 启动时报错（只有 HF 单极部分，连 Γ3 都不够） | | |

### 为什么 no2b 文件够用（除 λ3 项外）

no2b 文件存 V_no2b(ab c, de f; J12) = Σ_J (2J+1) ⟨(ab)J12, c; J|V|(de)J12, f; J⟩，c、f 同 (l, j) 通道（`ThreeBodyStorage_no2b`），
没有对 c 求和，与参考态无关。凡是"第三个粒子与标量一体量收缩、一对耦合到固定 J12"的收缩都能用它：
Γ3（第三个粒子与 γ1）、f3 的 γγ 部分、f3 的 λ2 部分（自由指标 p、q 充当第三个粒子，λ2 秩 0 使两对同 J12）、E3 的 γγγ 与 γλ2 项。
λ3 项需要两对 J12 不同、第三个轨道不同通道、按 J 分开的一般矩阵元，no2b 没有。代码里除 λ3 项外全部通过
`GetME_pn_no2b` 取矩阵元（full 存储由基类按 J 求和实现），两种格式共用一套代码。

### V3 拿不到 full 时的 λ3·V3 项

- λ3 只在部分占据的轨道（Nmax_ref 盒子内）非零，所以这一项只要六个指标都在盒内的 V3（E3 ≲ 3(e_F + Nrefmax)），
  比生产 full 文件小几个数量级。能用 NuHamil 生成的力，可以生成盒内的 full 小文件；只以 NO2B 发布的力只能取 0。
- 若参考态 NCSM 用显式 3N 算，⟨Ψ|H|Ψ⟩ = E_ref 本身包含这一项；驱动打印 `initial E - E_ref` 可核对。
- 这一项只平移绝对能量；当前估计（开壳 Nrefmax=0 最大）不超过亚 MeV，小于 IM-NCSM 其他误差，未实测。

## 3. 实现要点

- **在 HO 基里收缩，不变换 3N**：γ1_HO = C·n·Cᵀ，λ2 用 `TransformOneAndTwoBody(Cᵀ)` 转回 HO 对基，λ3 用 C⊗C⊗C 转回；
  得到的 f3、Γ3 再转到自然基，与 `MRReference::NormalOrder` 的 NN 结果相加。E3 的 γλ2 项 = `ContractLambda2(Γ3)`。
- Γ3 与 imsrg++ HF 的 3N→2B 公式相同（`HartreeFock::GetNormalOrderedH`），按二体通道 OpenMP 并行；E3max 截断同 HF。
- 驱动先算 MR-NO2B，再 `ThreeBody.Deallocate()` 释放 3N 存储，流期间不占 3N 内存。
- 对易子 λ3 项的 J 耦合形式：bra ((kl)J13, b)、ket ((cd)J12, m)，
  O^J = Σ_a Y^{J13}_{(kl),(am)} U X^{J12}_{(ab),(cd)}，U = (−1)^{jb+jm+J12+J13} Ĵ12 Ĵ13 {jb ja J12; jm J J13}，
  T = ¼ Σ_J (2J+1) Σ O^J Λ^J。与算符无关的部分（按 (旁观轨道, 对 J) 分组、6j、加权的 λ3 子块）对每个参考态只建一次
  （`MRReference::lambda3_commutator_plan`），每次调用只取需要的 X、Y 矩阵元；按通道并行、固定顺序求和，结果与线程数无关。
  耗时：He4 嵌入 emax6 约占一次 MR 对易子的 8%；emax2 下 SR 部分很小，占比约 40%。

## 4. λ3 的来源与约定

- 约定（`lambda3.py`、`Lambda3Channel`）：γ3^{abc}_{def} = ⟨a†_a a†_b a†_c a_f a_e a_d⟩，λ3 = γ3 − A(γ1γ1γ1) − A(γ1λ2)，
  在自然基计算（γ1 对角，A(γγγ) 只在三元组对角、A(γλ2) 只连共享轨道的三元组），只保留部分占据轨道。
  J 耦合块与 `ThreeBodyME::GetME_pn` 同约定：先 (ab) 耦合到 J12 再耦合 c，直接 CG、对不归一化；对 M 平均（秩 0 投影）；
  存 a ≤ b 的态，(ba) = (−1)^{ja+jb−J12+1}(ab)。于是 Σ_m V λ3 = Σ_J (2J+1) Σ_{不限制的态} V^J Λ^J。
- 生成：
  - `bigstick_jref.py` 默认写 λ3 和 BIGSTICK 本征值（jref v2），`--no-lambda3` 写 v1；
  - `export_jref.py --lambda3`（simpleFCI 原型，m-scheme 精确，作对照）；
  - `EmbedInModelSpace` 保留 λ3（新轨道上为 0）。
- 计算方式：由三湮灭振幅 A3（先把 HO 列旋转到自然轨道：a_{t'} = Σ_t det(U[t,t']) a_t）得 γ3 的秩 0 投影，
  再减去投影后的 A(γγγ)、A(γ1λ2)。规模受 A3 的列数（盒内 m 态三元组）限制，纯 Python，适合中等参考态。
- FCIQMC：量子化学已有 FCIQMC 的 3-RDM；接入后同样写成 jref v2 即可，程序侧不需要改动。

## 5. 输入示例

```bash
imsrg++ 2bme=He4.jcoupled64 fmt2=jcoupled64 \
  3bme=ThBME_NO2B_..._e3max16.me3j.gz 3bme_type=no2b e3max=16 file3e1max=14 file3e2max=28 file3e3max=16 \
  mr_reference_file=He4.jref ...（其余同纯 NN）
```

full 文件用 `3bme_type=full`。`nucleon_mass_correction=false`（J64 已含完整 NN 真空 H）。

## 6. 验收（`MRThreeBody`、`MRBigstickReference`）

He4 Nrefmax=2 相关参考态，全部对着由 m-scheme 波函数直接算的量：

| 检查 | 结果 |
|---|---|
| 随机（严格反对称）三体：E3（含 λ3 项 0.017）对 ⟨Ψ\|V3\|Ψ⟩ | 差 3e-12 |
| 随机三体：f3、Γ3 对 m-scheme 收缩 | 差 3e-12 |
| N3LO lnl 3N（emax6，ħω16，只作真实矩阵元来源）：no2b 对 full | 一体 1e-7、两体 8e-8（相对）、零体 3e-8（单精度存储） |
| 同上：full 的 E3（λ3 项 0.069）对 ⟨Ψ\|V3\|Ψ⟩ | 差 2e-9（Darmstadt 格式按 (ab)J12 c 存，过完备、单精度，不同顺序取出有 1e-8 级不自洽） |
| 对易子零体（含 λ3 项 −0.546）对 ⟨Ψ\|[X,Y]\|Ψ⟩ | 差 1e-11；不加 λ3 项差 0.546 |
| BIGSTICK 与 simpleFCI 两条路线的 λ3 | 差 3.7e-9（λ3 最大 1.1e-2） |
| 驱动（no2b / full × 有无 λ3）：初始 E 对库函数，日志与元数据 | 一致 |
