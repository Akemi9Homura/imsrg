# 参考态输入（jref）

MR 程序只读一种参考态文件：`mrimsrg_jref`（扩展名 `.jref`，版本 1；带 λ3 或参考能量时为版本 2）。不同求解器的输出都在程序外转成 jref，
C++ 侧只有一套读入与校验（`MRReference::ReadBinary`）。这样新增来源只需写一个适配器，自然轨道、λ2 等易错步骤只实现一次。

## 1. 内容与约定

| 字段 | 说明 |
|---|---|
| 头 | 魔数、字节序、版本；A、Z、Nrefmax、2J、宇称、emax、e2max、ħω；轨道数、通道数 |
| 摘要 | 三个 SHA-256：相互作用文件、密度、波函数（来源可追溯） |
| 轨道表 | 每个轨道 (n, l, 2j, 2tz) 与**自然轨道占据数**（每个磁子态的占据） |
| 自然轨道变换 | C[旧, 新]，HO 轨道 → 自然轨道，只在相同 (l, j, tz) 之间混合 |
| λ2 | 每个 (J, 宇称, Tz) 通道的对列表与矩阵：自然基下、归一化反对称对态、对 M 平均（秩 0）的两体累积量 |
| 参考能量（v2，可选） | E_ref 与 64 字节标签（哪个 H 算的，如 "BIGSTICK eigenvalue (float32), state 1"） |
| λ3（v2，可选） | 每个 (2J, 宇称, 2Tz) 通道的态 (a, b, c, J12)（a ≤ b）与矩阵：自然基、部分占据轨道上、秩 0 的三体累积量，约定见 三体力与λ3.md |

约定：

- γ1_ab = ⟨a†_{a m} a_{b m}⟩（标量，与 m 无关）；γ2_pqrs = ⟨a†_p a†_q a_s a_r⟩；λ2 = γ2 − γ1∧γ1。
- 参考态总 J = 0，只需秩 0 密度，但秩 0 包括所有对角动量 J 的块（J_bra = J_ket），不只是对 J = 0。
- λ3 可选：有 λ3 块（哪怕为空）表示"已知"，没有表示"未知"，程序按"有就用"处理；γ2、γ3 不单独存（由累积量重建）。
- 没有 λ3 和参考能量时写版本 1，与之前的文件逐字节相同；读入程序两种版本都接受。
- 对列表里的 (a, b) 用文件内轨道编号；C++ 按 (n, l, 2j, 2tz) 映射到 ModelSpace，遇到反序的对乘交换相位 (−1)^{j_a+j_b+J+1}（`e9816cd6` 修正）。

**自然轨道的标号规则**：每个 (l, j, tz) 块内按 γ1 的连通分量对角化，占据降序依次放到 n 升序的 HO 槽位，主元取正。
自然轨道继承槽位的 e = 2n + l，White-NCSM 的 Δe 掩码按这个标号（Vobig 6.5.3 节）。所有生成器都用这条规则，所以不同来源的 jref 可以逐元比较。

## 2. 生成方式

### 2.1 BIGSTICK（推荐）

`prototype/mrimsrg/bigstick_jref.py`

```bash
python3 -m prototype.mrimsrg.bigstick_jref \
    --bas X.bas --wfn X.wfn --interaction H.MFDn \
    --nrefmax 2 --hw 20 [--e2max E] [--state 1] [--no-lambda3] --output X.jref
```

默认同时写 λ3（三湮灭振幅，部分占据轨道）与 BIGSTICK 本征值（单精度），即 jref v2；`--no-lambda3` 写 v1。

- 输入：BIGSTICK 菜单 `n` 写出的 `.wfn`，以及**同一空间、同一截断**下菜单 `ba` 写出的 ASCII 基文件 `.bas`；
  `--interaction` 是 BIGSTICK 用的相互作用文件（只取 SHA-256）。示例输入在 `test/data/bigstick_He4_Nrefmax2/`。
- 为什么不用 BIGSTICK 自己的两体密度：菜单 `2d` 在 Nmax 截断空间里失败（"Problem cannot find sector jumps PP"），
  不截断时正常；上游 WHATSNEW 也记录过截断下两体密度的问题。参考态正是截断空间，所以从波函数自算。
- 算法：由组态和振幅构造一、二湮灭振幅 A1、A2（稀疏），γ1 = A1ᵀA1，γ2 的秩 0 投影
  γ2^J = (2J+1)⁻¹ Σ_M (A2 P_M)ᵀ(A2 P_M)（P_M 是耦合到 (J, M) 的归一化对投影），不形成 m-scheme 两体数组；
  然后自然轨道、对基转动、λ2 = γ2 − n_a n_b（自然基下在对角上）、写 jref。
- 必须对所有 M 平均：只取 M = 0 时，单精度波函数的微小 J 不纯会让 λ2 与 γ1 的收缩恒等式偏离约 2.6e-8，C++ 读入校验（1e-10）会拒绝；
  秩 0 投影下该恒等式代数成立。
- 精度：BIGSTICK 默认 `lanc_prec = 4`（单精度 Lanczos 向量，编译期参数），密度相对误差约 1e-7。读入支持 real4 与 real8 文件。
  He4 Nrefmax=2 与 simpleFCI 路径相比：占据数差 5e-9，自然轨道 6e-9，λ2 4e-8，λ3 4e-9（最大元素 1.1e-2）。
- 规模：组态读入与对投影是纯 Python 循环，适合中等维数；参考态很大时再换 C++。
- HF 基参考态：imsrg++ 单参考 `basis=HF smax=0 write_omega=true write_H_no2bpack=H_HF.no2bpack` 写出 HF 基 H（3N 为相对 HF 的 NO2B）
  与 HO→HF 矩阵 `<intfile>C.mat`；BIGSTICK 用 `no2` 读 H_HF.no2bpack 求参考态；转换时加
  `--basis-transformation <intfile>C.mat --basis-orbits H_HF.no2bpack`，写入 C_total = C_HF·C_nat（按 no2bpack 轨道顺序对齐，检查正交与轨道集合）。
  MR 驱动仍读 HO 基 NN + 3N，3N 相对该参考态重做 MR-NO2B。闭壳 Nrefmax=0 时这条链与单参考 HF-IMSRG 一致（`MRBasisReference`）。
  HF 基 NO2B 下算的参考态与 MR-NO2B 下的 H 不完全相同，驱动打印的 `initial E - E_ref` 量化这一差别。

### 2.2 simpleFCI 原型（小体系基准）

```bash
prototype/mrimsrg/build/mrimsrg_prepare --interaction X.minipack --output DIR --Z 2 --N 2 --nrefmax 2
python3 -m prototype.mrimsrg.export_jref --reference DIR --output X.jref [--lambda3]
```

在 m-scheme 下由行列式和 CI 系数算密度（≤ 64 个 m 态），再耦合成 J。只适合 emax2 这类小空间；目前固定 N2LO_opt、ħω = 20、emax2 的夹具，
作为其他来源的对照基准。`export_jref.py` 与 `bigstick_jref.py` 共用写出函数 `write_jref()`。

### 2.3 嵌入更大的 emax

参考态通常在小空间（Nmax_ref 盒子）算，流在大 emax 做。嵌入时新增轨道占据为 0、λ2 为 0、变换为单位阵：

```bash
python3 -m prototype.mrimsrg.embed_jref --source X_emax2.jref \
    --interaction target_emax8.minipack --output X_emax8.jref --pyimsrg-dir build/src
```

或在 Python 里 `MRReference.EmbedInModelSpace(target_modelspace, interaction_sha256)`。集群上
`gen_job.py --mr-prepare-jscheme` 同时生成目标 emax 的 J64 相互作用与嵌入参考态。

### 2.4 计划中：FCIQMC

fciqmc-mpi 的 j-scheme 后端输出 KSHELL 约定的秩 0 OBTD/TBTD。只需加一个适配层（约定换算），复用上面的自然轨道、λ2 与写出。

## 3. 读入时的校验（C++）

驱动先 `MRReference::ReadOccupationMap` 设置 ModelSpace 占据，再 `ReadBinary`。拒绝的情形：

- 魔数、版本、字节序不对；轨道数与 ModelSpace 不同；轨道或对无法一一映射；非空通道缺失；文件有多余字节；
- λ2 不对称、不厄米，或与 γ1 的收缩不一致（容差 `mr_validation_tolerance`，默认 1e-10）；
- λ3 的态与通道量子数不符（a ≤ b、J12 三角、同轨道 J12 偶、宇称、Tz）、重复、矩阵不对称。λ3 没有像 λ2 那样的收缩恒等式检查，
  其正确性由 `MRThreeBody` 测试对精确波函数量核对；
- 占据数与 ModelSpace 不符；占据落在 [1e-12, OCC_CUT = 1e-6)：SR 收缩会把这类轨道当空轨道（数值零 < 1e-12 允许，例如 He4 0d 约 1e-25）；
- 参考态 A、Z 与驱动的 `A`、`reference` 不符。

注意：驱动不会核对参考态是否由同一个相互作用算出（jref 里的相互作用摘要来自 NCSM 用的文件，格式不同于 imsrg++ 的 jcoupled64）。
可用的检查是驱动打印的初始能量 `MR initial natural-basis Hamiltonian: E=` 应等于 NCSM 参考能量。
