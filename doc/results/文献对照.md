# 文献对照（IM-NCSM，同一核力）

目的：确认 MR-IMSRG 接入 IM-NCSM 流程（参考态 → MR 流 → 导出 → BIGSTICK 后对角化）后，与已发表的同力结果大致一致。
不追求逐位一致（3N 处理、截断、生成元细节各家不同）；程序内自检必须自洽。

文献数据：`doc/data/literature/gysbers2026_O16_NNLOopt.json`、`doc/data/literature/gebrerufael2017_C12_O20_3NF400.json`
（从矢量图取点，精度约 0.05 MeV）。集群目录 `/tns/mengziyan/mr-imsrg/work/lit-20261026/`。

## 2. ¹²C、²⁰O，3NF400（NN + 3N）对 Gebrerufael 2017

力：N3LO EM500 NN + N2LO 3N（3NF400），SRG α = 0.08 fm⁴，ħω = 20（集群 `/tns/public/Forces/3NF400`，NO2B 文件 e3max = 14）。
流程（HF 基，Nrefmax = 0，见 参考态输入.md 2.1）：

1. imsrg++ 单参考 `basis=HF smax=0` 写出 HF 基 H（3N 为相对 HF 的 NO2B）与 HO→HF 矩阵；
2. BIGSTICK 在 HF 基 Nmax = 0 空间求参考态（完全对角化）；`bigstick_jref --basis-transformation` 写 C_total = C_HF·C_nat；
3. MR 驱动读 HO 基 NN + 3N，相对相关参考态做 MR-NO2B，White-NCSM 流，`mr_export_basis=natural` 导出；
4. BIGSTICK 在同一 MR 基里做 Nmax = 0/2/4 后对角化。

λ3 不用（文献同）。闭壳 O16 上这条链与单参考 HF-IMSRG 一致（测试 `MRBasisReference`）。

  White-NCSM 不解耦参考空间内部（Δe = 0）的激发。
- Vobig 2020 第 6.5 节（同组，提出 White-NCSM 的地方）正是因为 ¹²C 改的生成元：常规 White/ImTime 下 ¹²C 基态掉到大规模 NCSM 以下且不稳定、
  2⁺ 偏高、E(s) 与 Nmax 0 能量分离，判断为 NO2B 以外的诱导项过大（Gebrerufael 靠 ImTime 在 s ≈ 0.1–0.2 的"平台"取值，White 没有平台）；
  White-NCSM 下流稳定，基态更接近 NCSM、与 HFB 参考态的 MR-IMSRG 一致，激发态与 NCSM 相容；²⁰O 两种生成元都正常。
  文献 White 的 ¹²C E(s) 先降后升、与后对角化分离，正是这一现象；本程序收敛值比文献高 1.8 MeV、2⁺ 4.67 MeV（实验 4.44），方向与 Vobig 的结论一致。
  Vobig 的图用 ħω = 24，未作定量对照。
